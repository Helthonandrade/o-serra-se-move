# O Serra Se Move

Proposta interativa da BAITA para a Power Shape CT.

Site estático publicado no Render (`render.yaml`), sem etapa de build:

- `index.html` — página e conteúdo
- `assets/css/site.css` — identidade, tokens e layout
- `assets/js/dash.js` — dados da proposta (investimento, indicadores, concorrência, FAQ)
- `assets/js/app.js` — simulador, gráficos e totais
- `assets/js/cine.js` e `assets/js/site.js` — movimento, interações e barra de leitura
- `assets/img/` e `assets/fonts/` — imagens e fonte display

O site oficial da Power Shape permanece separado desta proposta.
